# CLoaKY233/homebrew-tap

Homebrew formulae for [siltop](https://github.com/CLoaKY233/siltop), a system monitor for Apple Silicon.

```sh
brew install cloaky233/tap/siltop
```

Formulae here are generated by siltop's release workflow. Please open issues and pull
requests in the [siltop repository](https://github.com/CLoaKY233/siltop).
